# Notebooks

Jupyter notebooks used for exploration, learning, visualization, and analysis.

## Purpose

Use notebooks to:

- Explore datasets
- Understand variables and dimensions
- Visualize NASA data
- Test statistical methods
- Experiment with machine learning
- Explore spatial data
- Record intermediate findings

## Structure

- `data_exploration/` — Dataset inspection and exploration
- `statistics/` — Statistical analysis
- `ml/` — Machine learning experiments
- `gis/` — GIS and spatial analysis
- `remote_sensing/` — Remote sensing analysis

## Guidelines

Notebooks are for exploration and learning.

Reusable logic should eventually be extracted into `src/`.

Avoid turning notebooks into the application's production code.

When a notebook produces an important result, document the result in `docs/experiments/`.
