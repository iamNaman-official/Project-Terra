# Tests

Tests for reusable Project Terra code.

## Purpose

Tests help verify:

- Data validation
- Statistical calculations
- Trend calculations
- GIS operations
- Machine learning utilities
- General software correctness

## Structure

- `data/` — Data-related tests
- `analysis/` — Statistical and analytical tests
- `ml/` — Machine learning tests
- `gis/` — Geospatial tests

## Principle

When experimental code becomes reusable code in `src/`, important behavior should have corresponding tests here.
