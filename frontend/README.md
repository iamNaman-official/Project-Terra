# Frontend

Web interface for Project Terra.

## Purpose

The frontend will eventually provide interfaces for:

- Exploring Earth-system data
- Viewing trends
- Displaying maps
- Visualizing statistical results
- Exploring detected anomalies
- Interacting with Terra's backend APIs

## Technology

- React
- TypeScript
- Vite
- Tailwind CSS
- Leaflet
- Plotly

## Principle

The frontend should consume processed results through APIs rather than directly handling large NASA datasets.
