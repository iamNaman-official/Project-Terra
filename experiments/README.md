# Experiments

This directory contains experimental code created while exploring ideas for Project Terra.

Experiments are allowed to be incomplete, exploratory, and imperfect.

## Purpose

Use this directory to:

- Test ideas quickly
- Explore NASA datasets
- Try statistical methods
- Experiment with machine learning
- Test GIS and remote-sensing techniques
- Compare different approaches
- Validate whether an idea is worth turning into reusable code

## Structure

- `data/` — Data processing and data-related experiments
- `statistics/` — Statistical analysis and trend experiments
- `ml/` — Machine learning experiments
- `gis/` — GIS and spatial analysis experiments
- `remote_sensing/` — Remote sensing experiments

## Workflow

Experiments should generally follow:

Experiment → Test → Validate → Document → Refactor

Successful experiments can later be moved into `src/` as reusable code.

## Important

This is a laboratory, not production code.

Do not worry about making experimental code perfect. Focus on learning, testing hypotheses, and recording what was discovered.
