# Backend

Django-based backend for Project Terra.

## Purpose

The backend will eventually provide APIs and application services for the Terra platform.

The backend should consume validated and reusable scientific functionality from `src/` rather than becoming the primary experimentation environment.

## Technology

- Python
- Django
- Django REST Framework
- PostgreSQL
- PostGIS

## Current Status

The backend is initially kept separate from the experimentation workflow.
